# AI Collaboration Instructions

## Workflow
- Read README.md and HANDOFF.md before starting.
- Check git status before modifying files.
- Respect the assigned role: developer or reviewer.
- Never edit files during a review unless authorized.
- Avoid simultaneous edits by multiple agents.

## Quality and Security
- Preserve existing functionality.
- Write clean and maintainable code.
- Protect credentials and sensitive data.
- Add regression tests for bug fixes.
- Run tests before declaring a task complete.

## Handoff
- Update HANDOFF.md after authorized implementation tasks.
- Document changes, test results and remaining issues.
- Identify the recommended next action.

## Git
- Never commit, push or merge without user approval.
- Preserve existing changes.
- Never perform destructive Git operations.
